# 第一课 · 从移动射击原型到三球靶场

双击本目录的 `NewGame.scene`，点 Play 并点击 Game 窗口。方向键移动，点按空格射击。

| 原型已有 | 本课新增或调整 |
|---|---|
| 方块移动、发射子弹、球体被击中后消失 | 把随机生成改成三颗固定位置的靶。学生可以反复练习同一条射击路线。 |
| 每帧读取移动输入 | 移动量按每秒速度乘 deltaTime；限制 X、Z 的活动范围，并保持统一高度。 |
| 子弹触发碰撞 | 用 Bullet 标签识别子弹。靶只销毁自身，打空的子弹在两秒后回收。 |
| 可以连续射击 | GameGraph 查找 Target 标签。最后一靶消失时显示通关提示；按 R 重载本关，中途也能重来。 |

**看图顺序**　从 Player 的 PlayerGraph 找到空格分支，沿 Instantiate 和 Add Force 看子弹怎样产生；随后打开 Enemy 图看命中条件，再到 GameManager 的 GameGraph 看清场判断。Rendering 文件夹存放本工程引用的 URP 管线与渲染器。

**试玩检查**　先故意打空，再依次击破三靶。检查通关提示是否在第三靶消失后出现，按 R 后是否恢复玩家起点和三颗靶。
