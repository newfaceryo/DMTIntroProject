# 第四课 · 命中反馈与胜利镜头

相较第三课，本课在命中时加入爆炸、音效和震屏；清场后切换胜利音乐与环绕镜头，再显示结算按钮。

在团结引擎打开 MyFourth_plus/ImpactRange.scene，选择 1080 × 1920 的 Game 视图。首次按键或点击进入，击破三个目标。最后一次爆炸后观察镜头推近并绕飞船转动；约 3.3 秒后出现「再玩一次」，点击直接开始下一局。

| 课堂步骤 | 对象和节点 | 可以改变什么 |
|---|---|---|
| 1. 让一次命中只触发一次反馈 | ImpactMeteor.prefab 的 MeteorHit 图沿用 On Trigger Enter → Compare Tag(Bullet) → If，加 Once；随后在陨石位置 Instantiate 爆炸预制体。 | Once 防止同一帧两颗子弹重复播放爆炸。BurstPrefab 是陨石的对象变量。 |
| 2. 把声音和画面放在同一处 | ImpactBurst.prefab 同时带 Particle System 和 Audio Source，生成时爆出 24 颗火星并播放本课生成的 MeteorImpact.wav。Stop Action 为 Destroy，特效播放完自动回收。 | Bursts 调火星数量，Start Speed 调扩散速度，Audio Source 的 Volume 调命中音量。 |
| 3. 让镜头对命中有反应 | MeteorHit 在生成爆炸后调用目标上 Cinemachine Impulse Source 的 Generate Impulse，再销毁陨石。Gameplay Camera 的 Impulse Listener 接收频道 1，主相机的 Brain 输出最终画面。 | Impulse Duration 当前 0.22 秒；调整 Listener 的 Gain 可改变震幅。 |
| 4. 清场后把镜头交给飞船 | FinalRound 判断没有 Target 后，关闭玩家的 Script Machine，然后启用飞船下的 Victory Rig。Victory Camera 优先级 30，高于 Gameplay Camera 的 10。Brain 用 0.75 秒平滑切换。 | 在 Victory Camera 的 Transposer 调 Follow Offset，在 Lens 调正交镜头大小。 |
| 5. 让镜头绕行，再展示按钮 | VictoryOrbit 图用 Update → Rotate，Y 轴角度接 65 × deltaTime。Transposer 跟随旋转的支点，Hard Look At 始终对准飞船。独立的 Start 协程等待 3.3 秒后打开 EndPanel。 | 转速和等待时间各由一个数值控制。结算页出现后镜头继续环绕，直到点击重玩。 |

本课使用工程已安装的 Cinemachine 2.10.7、URP 与 Visual Scripting。新增场景、图、预制体和音效均在 MyFourth_plus，飞船、陨石网格、星空和音乐继续引用 MyThird_Res。构建设置中追加了 ImpactRange。交付工程没有新增 C# 脚本。

实测覆盖首次开局、三次实际射击命中、独立爆炸实例、玩家输入锁定、胜利虚拟相机切换与支点旋转、延迟结算和直接重玩。命中音效随预制体配置，实际教室音量可在课前用机房扬声器调节。

## 环绕镜头切换胜利音乐

Victory Rig 启用时，VictoryOrbit 的 Start 节点先将现有 BGM 音源的 clip 换为「最终幻想胜利号角音效」，再调用 Audio Source → Play，随后等待 3.3 秒打开结算页。当前使用教师提供的 MP3，约 10.8 秒，沿用 BGM 音源的循环设置。点击「再玩一次」重载场景，BGM 自动恢复为 LunarRelay。要换曲，可在 Victory Rig 的对象变量 VictoryClip 中拖入新的 AudioClip。
