# 第二课 · 从清靶提示到开始与结算界面

双击本目录的 `RangeUI.scene`。本课沿用第一课的玩家、子弹、靶和命中图，为一局游戏加上两个 uGUI 面板。

| 相较第一课的变化 | 在哪里找 |
|---|---|
| 首次打开时出现标题、目标和按键说明；按任意键或点击画面即可开始。 | RoundCanvas → StartPanel。RoundUI 在 Late Update 读 anyKeyDown，隐藏开始页并启用玩家。 |
| 清除三靶后停止玩家操作，显示结算文字和「再玩一次」。 | RoundUI 用 Find With Tag、Null Check 和 Once 判断清场，关闭玩家并开启 EndPanel。 |
| 用按钮重玩，点击后直接恢复三靶并进入战斗。 | ReplayButton 写入 RangeUI_Replay 并加载本场景；RoundUI 在 Start 消费并复位该标记。 |
| 两个画面共用一个 Canvas。标题、说明、纯色背景和按钮都用 uGUI 搭建。 | Canvas Scaler 负责缩放，EventSystem 接收按钮点击，按钮用 Color Tint 提供按压反馈。 |

**试玩检查**　用空格开始，检查开局这一下是否误发子弹。击破三个靶后点击「再玩一次」，确认新一局无需再次点击开始。
