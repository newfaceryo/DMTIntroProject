# 第三课 · 从方块靶场到竖屏太空射击

双击本目录的 `SpaceRange.scene`，在 Game 视图选择 **1080 × 1920**。沿用第二课的开始页、清除三靶和直接重玩，把方块靶场改成有飞船、陨石、星空和音乐的完整场景。

| 相较第二课的变化 | 实现与调整入口 |
|---|---|
| 方块换成低多边形飞船，三颗球换成橙色陨石，子弹换成金色脉冲弹。 | 展开 Player 的模型子物体，或打开 Meteor.prefab、Pulse.prefab。碰撞和 Visual Scripting 留在父对象，外观可以单独更换。Pilot 图引用新子弹。 |
| 按竖屏重新构图。月面地平线、机库、天线和岩块在画面底部，中心留给射击。 | 主相机 Orthographic Size 为 8.3；原网格板和月面大网格的渲染器已关闭。基地装饰集中在 Lunar Relay Station。 |
| 加入静态星空与缓慢漂移、交错闪烁的近层星点。 | Orbital Sky 使用 Quad、512 × 1024 贴图和 URP/Unlit。Drifting Stars 使用 32 × 32 柔光贴图，每秒生成 6 颗，上限 40 颗。 |
| 加入循环背景音乐，并把开始页和结算页的目标文字改为陨石。 | BGM - Lunar Relay 以 0.29 音量播放本课原创的 20 秒 LunarRelay.wav。SpaceRound 和 ReplaySpace 使用本课的重玩标记。 |

**资源与渲染**　使用 URP/Simple Lit、Unlit 与粒子材质。飞船模型为 280 个三角形，陨石为 196 个三角形。模型来自 Kenney Space Kit，按 CC0 分发；原许可见同目录 Kenney-License.txt。[素材来源](https://kenney.nl/assets/space-kit)

**试玩检查**　用竖屏确认左右两颗陨石都能对准，近处星点在移动，开始页已播放背景音乐。清除三个目标后点击重玩，确认仍进入本课场景。
